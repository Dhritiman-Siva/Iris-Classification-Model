Executive Summary

The Iris Flower Classification Project delivers a robust, reproducible Machine Learning pipeline to identify Iris specimens into three botanical taxa—Iris setosa, Iris versicolor, and Iris virginica—leveraging four morphological measurements: sepal length, sepal width, petal length, and petal width.

1. Data Engineering & Sanitization

Starting from raw spreadsheet data (IRIS.xlsx with 150 instances), an automated pipeline performed quality assurance:

  • Null Inspection: 0 null or missing values were found across all fields.
  • Deduplication: 3 exact duplicate rows were identified and purged, yielding 147 clean, unique observations.
  • Class Balance: Post-cleaning class distribution remains balanced (Iris-versicolor: 50, Iris-virginica: 49, Iris-setosa: 48).
  • Clean Dataset Export: Persisted as iris_cleaned.csv.

5. Deployment & Inference Demonstration

The champion Random Forest model is serialized to iris_classifier_model.joblib (161 KB). The system provides full probability calibration:

# Quick Inference Snippet
import joblib, pandas as pd

model = joblib.load('iris_classifier_model.joblib')
sample = pd.DataFrame([[5.1, 3.5, 1.4, 0.2]], 
                      columns=['sepal_length', 'sepal_width', 'petal_length', 'petal_width'])

predicted_species = model.predict(sample)[0]        # 'Iris-setosa'
probabilities = model.predict_proba(sample)[0]      # [1.0, 0.0, 0.0]
